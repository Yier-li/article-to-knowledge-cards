# make-knowledge-cards

一个 WorkBuddy / Claude 技能（Skill）：把一篇文章提炼成 **5~8 张知识卡片**，  
每张卡片只讲一个知识点，用于复习和自测。

## 1. 项目解决什么问题

读完一篇文章，常见的结果是：当时看懂了，过几天只剩个模糊印象。

现有的三种补救办法都不太好用：

- **划重点 / 复制原文**——抄下来的是句子，不是知识，而且往往抄了一堆不值得记的。
- **让 AI 写摘要**——摘要追求"覆盖全文"，读起来通顺，但太长了记不住，  
  而且容易把原文没有的东西写得像原文说的。
- **自己整理成笔记**——质量最高，但慢，且判断"哪些值得记"这件事本身就很难。

本技能要解决的就是最后那一步：**判断什么值得记，并把它变成能被检验的最小单位**。  
它不追求覆盖全文，只产出 5~8 个真正重要的知识点，每个知识点压成一张卡片——  
脱离原文也能读懂，读完之后能自测有没有真的记住。

设计上有一条硬红线：**绝不编造**。卡片里的每个论断都能在原文找到出处，  
信息不够就少出几张，不凑数。

## 2. 主要功能

| 功能        | 说明                                            |
| --------- | --------------------------------------------- |
| 两种输入      | 直接粘贴正文，或给本地 `.md` / `.txt` / `.markdown` 文件路径 |
| 筛选真正重要的   | 五道关卡：溯源、独立性、知识性、一卡一点、去重，任一关不过就淘汰              |
| 一卡只讲一个知识点 | 一句话里并列两个独立论断就拆开；对比句是一个判断的两半，不拆                |
| 自动去重      | 按"断言同一性"判重（两张卡的核心知识互换后读者得到的信息是否不变），不看字面重叠     |
| 四段式卡片     | 标题 / 核心知识 / 简明解释 / 例子或自测问题                    |
| 可自测       | 原文没例子时出一道自测题，**并附答案**，答案必须能在原文找到              |
| 不凑数       | 凑不够 5 张就出实际数量，并在文末说明原因                        |
| 观点文识别     | 评论类文章在头部统一声明"结论多为作者主张"，避免把观点伪装成事实             |
| 可追溯       | 卡片按原文顺序排列，文末「说明」交代被合并/舍弃的内容和原文局限              |

篇幅约束：`核心知识` ≤ 40 字，整卡 80~180 字。

## 3. 安装方法

本技能无脚本依赖，纯提示词驱动。把 `skills/make-knowledge-cards/` 整个目录  
复制到技能目录即可：

| 范围          | 目标路径                                           |
| ----------- | ---------------------------------------------- |
| 用户级（所有项目可用） | `~/.workbuddy/skills/make-knowledge-cards/`    |
| 项目级（随仓库共享）  | `<项目>/.workbuddy/skills/make-knowledge-cards/` |

目录内容：

```
skills/make-knowledge-cards/
├── SKILL.md              # 技能主体：工作流、质量红线、输出格式
├── agents/openai.yaml    # 界面元信息（显示名、图标、默认提示词）
└── assets/               # openai.yaml 引用的两个 SVG 图标
```

## 4. 使用方法

不需要记命令，用自然语言触发即可：「做成知识卡片」「提炼重点」「整理成复习笔记」  
「帮我记住这篇文章」。

**输入 —— 两种方式：**

```text
# 方式一：直接粘贴正文
把下面这篇文章做成知识卡片：
<粘贴正文>

# 方式二：给本地文件路径
把 ./notes/索引原理.md 做成知识卡片
```

**输出 —— 落盘位置**（优先级从高到低）：

| 情况            | 输出位置                              |
| ------------- | --------------------------------- |
| 指定了路径         | 用指定的路径                            |
| 输入是文件，未指定路径   | 源文件同目录，`<源文件名>-知识卡片.md`           |
| 输入是粘贴文本，未指定路径 | 当前工作目录，`知识卡片.md`（已存在则加 `-2`、`-3`） |

输出文件为 UTF-8 编码。卡片内容会**同时在对话里完整展示**，不是只丢一个文件路径。  
一次给多个文件时，默认每个文件单独产出一套。

**遇到不支持的输入**（网页链接、PDF、Anki、GUI）时，技能会明确说明不支持并给出  
替代方案（例如"把这个 PDF 导出成 txt 后再给我"），不会尝试变通处理或假装成功。

## 5. 输入输出示例

### 输入

一篇关于"遗忘曲线"的科普文（约 1100 字），节选：

```markdown
几乎每个做过学习方法功课的人都见过那条陡峭的曲线：学完 20 分钟忘掉 42%，
一天后忘掉 67%，一个月后忘掉 79%。……但绝大多数引用它的人，都漏掉了两个关键前提。

第一个前提：艾宾浩斯记忆的不是知识，而是无意义音节。……这条曲线描述的是最坏情况。

……提取记忆本身是一件有认知成本的事：当你在快要忘记的边缘重新回想一个内容时，
大脑需要付出更多努力去重建这条记忆通路，而这次费力的重建会强化它。
```

### 输出

生成 `遗忘曲线-知识卡片.md`，共 8 张，以下为其中 2 张（其余略）：

```markdown
# 知识卡片：被误读的"遗忘曲线"

> 来源：./notes/遗忘曲线.md｜卡片数：8

### 卡片 1｜那条陡峭的遗忘曲线，测的是毫无意义的材料

- **核心知识**：那条陡峭的遗忘曲线，测的是与已有知识毫无关联的材料。
- **简明解释**：艾宾浩斯用的材料是"ZOF""WUX"这类无意义音节，他刻意排除掉意义与
  联想的影响，测量的是纯粹的机械记忆衰减。所以这条曲线描述的是最坏情况。
- **例子**：学完 20 分钟忘掉 42%、一天后 67%、一个月后 79%，
  就是用这类无意义音节测出来的。

### 卡片 4｜越费力的提取，对记忆的强化越强

- **核心知识**：越接近忘记的边缘才重新回想，对记忆的强化越强。
- **简明解释**：主流解释是"必要难度"。在快要忘记的边缘回想，大脑需要付出更多努力
  重建记忆通路，这次费力的重建会强化它；刚学完立刻重复则几乎不产生强化。
- **自测问题**：为什么刚学完立刻重复，几乎不产生强化效果？
  - 答案：因为刚学完时提取太容易，不需要费力重建记忆通路。

## 说明

- **卡片数量**：8 张，符合 5~8 张的目标区间。
- **被合并或舍弃的内容**：结尾四条操作建议已逐条并入对应卡片，未单独成卡。
- **原文局限**：文章未给出实验样本与原始出处，卡片未补充任何原文之外的数据或引文。
```

### 边界：信息不足时不凑数

输入一篇 260 字的新闻快讯（某公司收购某公司，含成立时间、团队规模、交割时间），  
输出**只有 1 张**，并在「说明」里写清原因：

```markdown
> 来源：./notes/收购快讯.md｜卡片数：1

### 卡片 1｜这次收购的目的是补强非结构化数据的摄取能力

- **核心知识**：Snowflake 收购 Datavolo，意在强化对 PDF、图像、音频的摄取处理。
- **简明解释**：Datavolo 主打基于 Apache NiFi 的非结构化数据摄取能力，这正是
  Snowflake 平台原有能力之外的部分。厂商声明的收购目的即补上这一环。
- **自测问题**：Snowflake 方面表示，此次收购将强化哪一类数据的处理能力？
  - 答案：PDF、图像、音频等非结构化数据。

## 说明

- **卡片数量**：1 张，远低于 5~8 张的目标区间。这是如实结果，不是省略。
- **为什么只有 1 张**：全文约 260 字，属事件性快讯，主体是交易事实（收购方、标的、
  成立时间、团队规模、交割时间、金额未披露）。事实罗列不构成可迁移的知识点，
  不予立卡。全篇只有"收购目的"这一处带可迁移的判断成分，因此只产出 1 张。
- **未做的事**：没有把"团队约 40 人""成立于 2023 年""Q4 交割"拆成卡片凑数，
  也没有补充原文没有的行业背景或趋势判断。
```

## 暂不支持

网页抓取、PDF / Word / 图片 / 扫描件、Anki 导出（`.apkg`）、图形界面。

## 验证

```bash
python <skill-creator>/scripts/quick_validate.py skills/make-knowledge-cards
# Skill is valid!
```

已在四类素材上实测：科普文、技术教程、观点评论、新闻短讯（信息不足场景）。
